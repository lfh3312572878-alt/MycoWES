# Representative selection and reference exclusion

The preserved `reproduce/historical/metadata/REFERENCE_ARM_ASSEMBLY_MANIFEST.tsv` has SHA256 `88a5f0ea9a7d7b225505107bc44968e29648cd23e8d96f6b3babccf7ab6819a6`, exactly matching `selection_manifest_sha256` in the one-representative identity. It describes 67 target assemblies, 18 selected targets and the complete 560-assembly competitor set. The 18 selected accessions match the distributed one-representative taxonomy. `representatives.tsv` exposes this final selection without requiring large FASTA files.

The original `build_reference_arm_manifest.py` selects the minimum frozen `quality_rank_within_species_v0.8`, then `selection_order_within_species_v0.8`, then accession. Original inventory fields include assembly level, RefSeq category, CheckM completeness/contamination, N50, contig count, cluster membership and the prior retained decision. The file and builder are provided, not rerun to reselect genomes. `build_one_rep_reference.py` filters an explicitly supplied manifest/taxonomy/FASTA and checks the expected 18-target/560-competitor counts.

This closes the selection-manifest omission but not every provenance claim. The raw ranking-generation calculation, complete original selection-order input and independent timing record establishing prespecification were not recovered in this revision. The original builder's statements about quality criteria and its PRESPECIFIED labels are preserved as historical declarations, not independently validated facts. Do not describe benchmark-independent prespecification as proved solely by those strings.

The baseline exclusion manifest removes GCF_900118515.1 (22 contigs) as an operational reference-attractor observation. The original v0.28 builder and source path are provided. This does not establish biological contamination of that assembly. The available four-sample observation does not by itself supply a matched cohort-wide before/after ablation, and contains patient-linked material that is not included in this code package. A deidentified matched before/after summary, the original ablation commands/configuration and its source identity are still needed before retaining an unqualified VALIDATED_BY_ABLATION claim in prose. Original exclusion metadata and database bytes are not edited.
