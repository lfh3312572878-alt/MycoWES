# Resource and analysis terms

| Historical identifier | Meaning |
| --- | --- |
| A and B / AB | Target compartment: core target species and the extended human-associated target set |
| C, D and E / CDE | Competitor compartment: broader Mycoplasma background (C), other Mycoplasmatota outgroups (D) and external bacteria (E), following recorded role labels |
| JOINT | Competitive alignment against the selected target compartment plus the complete competitor compartment |
| one representative | One selected genome assembly per target species for competition; not a restriction of the anchor target FASTA |
| RELAX2 | Single-representative quality choice 60 aligned bp / MAPQ5 / NM0.12; CLI preset relax2 |
| DF2 | Capture intervals supported by at least two design families; an additional STRICT exclusion |
| PRIMARY | Target fragment candidates passing the executed quality, shared-risk and adapter rules |
| STRICT | PRIMARY with the additional supplied DF2 capture overlap exclusion |
| anchor | Species assembly chosen by retained paired-fragment support and tie-breaks for coordinate/dispersion assessment |
| physical span | Outer paired-fragment interval, including the insert between mates; not aligned-base coverage |

Historical path keys containing DEVELOPMENT, RESEARCH or BETA are retained for resource compatibility and provenance, not used as evidence grades. Paper counts and member selection follow each recorded experiment rather than these names.
